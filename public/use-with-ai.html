Quickest start — paste one line

In any assistant that can open links (Gemini, ChatGPT, Claude), paste this:

Use the UCSB innovation data at https://ucsbie.vercel.app/data/ucsb-ie.json to answer my questions about UCSB technologies available for licensing and UCSB ventures. When I'm interested in licensing a technology, tell me to contact info@innovation.ucsb.edu with the technology title and Tech ID.

Google Gemini Gem ⭐

UCSB's licensed AI. Best no-code option.

  1. Go to Gemini → Gems → New Gem.
  2. Name it UCSB Innovation Assistant.
  3. In Instructions, paste this: 
    You are the UCSB Innovation Assistant. You help people explore technologies available for licensing from UC Santa Barbara and ventures that have emerged from UCSB research, using the attached UCSB data.

- Answer questions about UCSB technologies available for licensing and UCSB ventures: what exists in a field, inventors/founders, disclosure year, patent status, company status/sector/funding.
- When asked "what's available in <field>", list relevant technologies with Tech ID, a one-line summary, and disclosure year. For ventures, give status, sector, founding year, and disclosed capital.
- Distinguish a technology's AGE (disclosed year, from the UC case) from its RECENCY on the marketplace (higher Tech ID). Note that category counts overlap.
- Distinguish UCSB Startups (license UCSB IP) from UCSB Affiliated Startups (no UCSB IP license) when relevant.
- Ground every answer in the provided data. If something isn't in the data, say so and point to the source.

Connecting people:
- For licensing interest, tell the user to contact UCSB's Innovation & Entrepreneurship team at info@innovation.ucsb.edu and include the technology title and Tech ID. Offer to draft that email.
- For investor/partner interest in a venture, suggest the company website (if listed) and an introduction via info@innovation.ucsb.edu. Offer to draft the outreach.

Tone: concise, accurate, helpful. This is public information; for anything authoritative, defer to info@innovation.ucsb.edu.
  4. Under Knowledge → Add files, upload both CSVs (download above): ucsb-technologies.csv and ucsb-ventures.csv. (A Gem accepts up to 10 files.)
  5. Save. Try: "What battery technologies can we license?" or "Which active healthcare startups raised the most?"

ChatGPT — Custom GPT

  1. Go to ChatGPT → Explore GPTs → Create.
  2. Paste the same instructions from the Gemini section (the Copy button above works here too).
  3. Under Knowledge, upload the two CSVs. (For always-current data instead, use the Action in the next section.)

Claude — Project

  1. Create a Claude Project (or just drop files into any chat).
  2. Add ucsb-technologies.csv + ucsb-ventures.csv (or ucsb-ie.json) to Project knowledge.
  3. Paste the instructions from the Gemini section.

Live API — always current (Custom GPT Action / Gemini)

The site exposes a small read-only API. Try these in a browser:

/api/technologies?field=Semiconductors /api/ventures?status=Active&licensed=true /api/categories

Add it to a Custom GPT (Action)

  1. In the GPT editor → Actions → Import, paste this schema URL:
https://ucsbie.vercel.app/openapi.yaml

No authentication needed — it's public data. For Gemini, feed the same OpenAPI operations to the Gemini API as function declarations.

MCP server — real-time tools in your agent (developers)

One server works in Claude Desktop/Code, the Gemini CLI, and ChatGPT developer mode / OpenAI Agents SDK.

pip install "mcp>=1.2" requests
git clone https://github.com/kcaylor/ucsbie.git
python ucsbie/mcp/ucsbie_mcp.py

Register it (Claude Desktop / Claude Code)

{
  "mcpServers": {
    "ucsbie": { "command": "python", "args": ["/ABS/PATH/ucsbie/mcp/ucsbie_mcp.py"] }
  }
}

Register it (Gemini CLI — ~/.gemini/settings.json)

{
  "mcpServers": {
    "ucsbie": { "command": "python", "args": ["/ABS/PATH/ucsbie/mcp/ucsbie_mcp.py"] }
  }
}

Replace /ABS/PATH with where you cloned the repo. Tools: tech_list, tech_get, tech_search, tech_categories, startups_list.

Command-line tool (developers)

pip install requests
git clone https://github.com/kcaylor/ucsbie.git && cd ucsbie
python -m ucsbie tech search "photonics" --details
python -m ucsbie startups list --filter licensed --format csv --out ventures.csv

JSON by default; add --format csv or --format table, and --out FILE.
